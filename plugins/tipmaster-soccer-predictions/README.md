# TipMaster Expert Soccer Predictions

Compare football predictions from TipMaster's Top 20%, Top 25% and All players,
with published sample sizes and measured accuracy. TipMaster has run its free
prediction game since 1997.

Ask about a match, a league's upcoming fixtures, this week's Classic round, or
whether the experimental model outperforms player groups. The included skill
uses seven public, read-only tools. National can provide exact scores; Classic
records home/draw/away predictions. Expert groups appear after the deadline.
Prediction shares describe agreement, not calibrated probabilities or guarantees.

No TipMaster account or API key is needed. The connection sends match and
competition filters to TipMaster and returns aggregate statistics. Public shares
need at least 20 players, and accuracy rates need at least 50 published matches.
The model benchmark includes its dates, sample sizes and limitations.

This package stores no account data and cannot submit predictions or make
payments. To play your own game, use the separate **TipMaster Coach** plugin.
